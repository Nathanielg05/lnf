# Lost And Found App

Physically the process of finding and submitting lost items is very tedious. When trying to locate a lost item, especially on campus, 
the lost and founds are not only scattered anywhere but are completely disorganized and un-secure in what
they may have. With this system, the many lost and founds can become one centralized online
hub significantly decreasing the complexity of finding a lost item.


This application will be used by people who both found or lost an item as well as an admin that
keeps track of the items in the lost and found database.
